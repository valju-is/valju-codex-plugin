# Contributing

Issues and pull requests for public documentation, plugin metadata, and the Valjú skill are welcome.

Do not submit private backend code, credentials, access tokens, customer information, production data, or internal infrastructure details. Security reports must follow [SECURITY.md](SECURITY.md).

Before submitting a change:

1. Keep the plugin identifier `valju` stable.
2. Use semantic versioning in `plugins/valju/.codex-plugin/plugin.json`.
3. Validate the plugin manifest and JSON files.
4. Test installation from a clean local marketplace configuration.
5. Start a new Codex thread and exercise the affected skill or tool behavior.
