# Contributing

Issues and pull requests for public documentation and Valjú MCP connection examples are welcome.

Do not submit private backend code, credentials, access tokens, customer information, production data, or internal infrastructure details. Security reports must follow [SECURITY.md](SECURITY.md).

Before submitting a change:

1. Keep the MCP server identifier `valju` and endpoint stable.
2. Validate all JSON examples.
3. Test the affected setup flow in ChatGPT, GitHub Copilot, or Claude.
4. Keep client-specific instructions linked to the client's official documentation.
