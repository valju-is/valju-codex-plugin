# Security policy

## Reporting a vulnerability

Please do not open a public issue for suspected security vulnerabilities or exposed credentials.

Report security issues privately through the security contact published at <https://valju.is> and include reproduction steps, affected components, and the potential impact. Valjú will acknowledge the report and coordinate remediation and disclosure where appropriate.

## Scope

This repository contains the public Valjú MCP integration guides and connection examples. Vulnerabilities involving authentication, authorization, the hosted MCP endpoint, or Valjú account data should also be reported privately rather than demonstrated against production accounts.
